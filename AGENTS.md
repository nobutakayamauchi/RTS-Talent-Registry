# AGENTS Instructions

## Status
**COLD / FROZEN GOVERNANCE SKELETON / EXPLICIT REFERENCE ONLY**

This repository is a frozen governance registry skeleton for external AI-related candidates such as repositories, skills, MCP servers, and agent profiles. It is not an execution runtime, recruiting CRM, personal-data registry, or canonical implementation source.

## Load rule
Do not include this repository in ordinary cross-repository implementation discovery or architecture selection.

Open it only when the task explicitly concerns:
- candidate intake/scoring/promotion/retirement rules;
- historical Talent Registry design;
- review of whether the registry should be revived, replaced, or retired.

Candidates are references, not authorities.

## Guardrails
- Do not add secrets, credentials, private links, executable integration code, human personal data, recruiting CRM behavior, scraping/surveillance, or automatic external mutation.
- Do not embed upstream manifests directly; store only references/governance metadata when explicitly working here.
- Do not promote candidates automatically.
- Do not treat this repository as RTS core, RTS-AGE, or source of truth for another repository.

## Stop condition
If the active task does not explicitly concern the Talent Registry, stop reading this repository and use the relevant active canonical source instead.
